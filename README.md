# EntraID-Lab
Ce projet permet de structurer et administrer une organisation dans Entra ID

## Objectif

Automatiser le déploiement d'une organisation fictive
dans Microsoft Entra ID.

## Fonctionnalités

- Création automatique des groupes
- Création automatique des utilisateurs
- Affectation automatique aux groupes
- Génération d'un rapport CSV
- Calcul de l'ancienneté des comptes

## Technologies

- PowerShell 7
- Microsoft Graph
- Microsoft Entra ID
